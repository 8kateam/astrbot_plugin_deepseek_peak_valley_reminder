# astrbot_plugin_deepseek_peak_valley_reminder

DeepSeek 峰谷时段提醒插件。根据当前时间自动判断 DeepSeek API 处于峰时计价还是谷时计价，并在计价时段切换时向配置的群聊/私聊推送提醒消息。

## 功能特性

- ⏰ **定时推送**：基于 APScheduler 的 cron 任务，在工作日 9:00、12:00、14:00、18:00（UTC+8）四个计价切换点准点推送提醒，精确到秒级
- 📅 **周末全天谷时**：适配 DeepSeek 新计价规则，周六周日全天按谷时计价，不发送切换提醒，可配置开关
- 💬 **双路径推送**：
  - QQ 群聊/私聊：通过 OneBot v11 原生 API 发送，支持多个 Bot 实例同时尝试
  - 其他平台：填写完整 `unified_msg_origin`，走 AstrBot 标准 `send_message` 通道
- 🎲 **多条文案随机**：峰时/谷时提醒文案均可配置多条，每次发送随机抽取一条，避免内容重复单调
- 🔧 **灵活配置**：每个切换点可独立开关，支持自定义时区与提醒文案
- 🔍 **查询指令**：随时查询当前计价状态

## DeepSeek 计价时段

以 UTC+8 为基准：

| 时段 | 时间范围 | 计价 |
|------|----------|------|
| 峰时 | 周一至周五 9:00 - 12:00 | 较高 |
| 谷时 | 周一至周五 12:00 - 14:00 | 优惠 |
| 峰时 | 周一至周五 14:00 - 18:00 | 较高 |
| 谷时 | 周一至周五 18:00 - 次日 9:00 | 优惠 |
| 谷时 | **周六、周日全天** | 优惠 |

> 周末（周六、周日）DeepSeek API 全天按谷时计价，插件已适配该规则。可通过 `enable_weekend_valley` 配置项开关此行为。

## 使用说明

### 第一步：获取会话 ID

在需要接收提醒的群聊或私聊中发送：

```
/dsid
```

机器人会返回当前会话的信息：
- **QQ 平台（aiocqhttp）**：显示群号或 QQ 号，按提示填入对应配置项即可
- **其他平台**：显示完整的 `unified_msg_origin`，填入 `target_sessions` 配置项

> 也可以使用 AstrBot 原生的 `/sid` 命令获取完整 `UMO`。

### 第二步：配置推送目标

在 WebUI 插件配置中，将获取到的 ID 填入以下任一配置项：

| 配置项 | 适用场景 | 示例 |
|--------|----------|------|
| `target_groups` | QQ 群聊 | `["123456789", "987654321"]` |
| `target_users` | QQ 私聊 | `["10001", "114514"]` |
| `target_sessions` | 其他平台 / 高级用法 | `["telegram:FriendMessage:10001"]` |

三类配置可以同时使用，互不影响。

### 第三步：等待推送或主动查询

- 到达配置的切换点时，机器人会自动推送提醒
- 随时发送 `/ds` 可查询当前计价状态：

```
/ds
```

## 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable` | bool | `true` | 定时提醒总开关 |
| `enable_weekend_valley` | bool | `true` | 周六周日全天视为谷时计价（适配 DeepSeek 新规则），关闭后恢复旧的按小时判定逻辑 |
| `timezone` | int | `8` | 时区偏移（小时），有效范围 `-12` ~ `14`（UTC+13/14 为汤加、基里巴斯等地的真实时区），负数为西时区（如 `-5` 表示 UTC-5），超出范围自动回退为默认值 `8` 并记录警告日志 |
| `target_groups` | list | `[]` | 推送目标 QQ 群号列表 |
| `target_users` | list | `[]` | 推送目标 QQ 号列表（私聊） |
| `target_sessions` | list | `[]` | 完整 `unified_msg_origin` 列表 |
| `remind_points.peak_morning_start` | bool | `true` | 9:00 峰时开始提醒（仅工作日） |
| `remind_points.valley_noon_start` | bool | `true` | 12:00 谷时开始提醒（仅工作日） |
| `remind_points.peak_afternoon_start` | bool | `true` | 14:00 峰时开始提醒（仅工作日） |
| `remind_points.valley_evening_start` | bool | `true` | 18:00 谷时开始提醒（仅工作日） |
| `peak_start_message` | list | （内置两条） | 进入峰时的提醒文案，随机抽取一条 |
| `valley_start_message` | list | （内置两条） | 进入谷时的提醒文案，随机抽取一条 |

### 文案占位符

提醒文案支持 `{time}` 占位符，发送时会替换为当前时间（`HH:MM` 格式），例如：

```
⚡ DeepSeek API 已进入峰时计价时段（{time}）
峰时时段：9:00-12:00, 14:00-18:00
调用 API 费用较高，请注意控制用量。
```

## 指令列表

| 指令 | 说明 | 适用平台 |
|------|------|----------|
| `/ds` | 查询当前峰谷计价状态 | 所有平台 |
| `/dsid` | 获取当前会话 ID 信息，用于配置推送目标 | 所有平台 |

## 注意事项

- QQ 群聊/私聊推送依赖 **OneBot v11（aiocqhttp）** 平台适配器；若配置了多个 Bot 实例，会向所有实例尝试发送，Bot 不在目标群/无该好友时会在日志中记录失败信息
- `target_sessions` 中的完整 `unified_msg_origin` 与平台实例绑定，更换平台配置后需重新获取
- 修改配置后建议重载插件使定时任务生效
- 推送失败不会中断其他目标的发送，具体失败原因请查看 AstrBot 日志

## 环境要求

- AstrBot >= 4.x
- Python 3.10+
- 依赖：`apscheduler>=3.10,<4.0`（随插件自动安装）
